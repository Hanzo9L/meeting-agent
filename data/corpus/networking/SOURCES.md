# Source Map

https://github.com/SystemsApproach/7E

The corpus uses the following upstream sections as conceptual anchors. The text in this corpus is rewritten and reorganized rather than copied wholesale.

- DNS concepts: RFC 1034 — https://www.rfc-editor.org/rfc/rfc1034.html
